MEDCHECK — анкета + кабинет врача

Проект уже подключён к Supabase.

Файлы:
- index.html — анкета для студентов
- admin.html — закрытый кабинет врача
- config.js — подключение к Supabase
- schema.sql — схема базы и RLS

Что уже настроено:
- таблица medical_questionnaires создана в Supabase;
- публичная форма может только ДОБАВЛЯТЬ анкеты;
- публичное чтение анкет запрещено;
- кабинет врача читает и обновляет записи только для пользователей, внесённых в medcheck_doctors;
- service_role key нигде не используется.

Что осталось перед публикацией:
1. В Supabase > Authentication > Users создать учётную запись врача (email + пароль).
2. Скопировать UUID пользователя.
3. Добавить его в список врачей SQL-командой:
   insert into public.medcheck_doctors (user_id) values ('UUID_ПОЛЬЗОВАТЕЛЯ');
4. Разместить папку сайта на HTTPS-хостинге.
5. Студентам дать ссылку на index.html, врачу — admin.html.

Важно:
Анкета содержит персональные и медицинские сведения. Перед реальным использованием согласуйте текст согласия, сроки хранения и правила доступа с ответственным за персональные данные/юристом вашей организации.
